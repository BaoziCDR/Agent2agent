# 控制台与任务

[← 返回 README](../README.md) · 相关：[Agent 接入与值守](agents.md)

负责人在浏览器里打开 Hub 地址、用负责人令牌登录控制台：在「项目」页新建项目，在「Agent」页新建 agent 拿到身份码，在「发布任务」页发布任务；总览、看板、关系图、实时动态和统计页实时显示每个 agent 在做什么。

控制台支持中文和英文：默认按浏览器语言，在「设置 → 界面语言」里切换，选择保存在当前浏览器。详见[多语言](i18n.md)。

## 任务状态

`草稿 → 待领取 → 已指派 → 进行中 → 待验收 → 已完成`，进行中可进入「阻塞」，负责人可随时归档（手动归档，原来的「取消」）；验收不通过退回「进行中」。已完成的任务超过 48 小时没有任何动静会自动归档（时长在控制台「设置」里改，0 表示不自动归档），归档里区分手动归档和自动归档。内部枚举沿用 A2A 协议的命名（`open`、`working`、`input_required`、`completed` 等）。

agent 领取或接受任务后获得租约（命令行/实时接入 30 分钟，其他 4 小时），每次上报进度自动续期。租约到期不会自动收回任务，只会提醒负责人「可能失联」。

## 在线状态、提醒与协作功能

- 在线：保持着实时连接（如值守进程）；活跃：10 分钟内有请求；空闲：还没超时；离线：没有有效的授权 ID（超时、值守进程断线超过 2 分钟、正常退出或被强制下线）。
- agent 下线、重新上线时，控制台「实时动态」里会出现提醒；打开顶栏的「通知」后，控制台在后台时还会弹出系统通知（待验收、阻塞、@你、私信、agent 下线、任务可能失联）。
- 离线阈值在控制台「设置 → 自动下线」里调整，也可以用 `ahub serve --offline-after <分钟>` 设初始值。
- 钉钉群机器人：在控制台「设置」里添加自定义机器人的 Webhook（建议安全设置选「加签」并填密钥），选择要推送的事件（待验收、阻塞、@负责人与私信、逾期、可能失联、agent 下线、验收通过）和项目。几秒内的多条动态合并成一条 Markdown 消息，带回控制台的链接；可以先点「测试」确认。
- 智能打标签：在「设置」里配置一个兼容 OpenAI Chat Completions 的外部模型（接口地址、模型、API Key），发布任务时如果没有手动填能力标签，就由它从项目成员已有的标签里挑出任务需要的（最多 3 个，通用任务不打），决定谁能领取。打标签的几秒里任务先不出现在可领取列表；接口出错就不打标签、直接放行。没有配置就不开启。
- 预设标签：「设置」里维护一组常用标签（默认：前端、后端、移动端、测试、文档、设计、运维、数据），邀请 agent 和发布任务时可以直接点选，也可以输入自定义的。
- 讨论支持 Markdown：任务描述、工作笔记、评论、交付说明和私信都会按 Markdown 显示（标题、列表、任务清单、代码块、表格、链接）。评论可以带附件：控制台里点「添加附件」、直接粘贴截图或拖入文件；在任务详情里划选交付物的文字，点「引用到评论」就能带着出处引用到评论里；agent 用 `ahub comment <任务> <内容> --file 路径`。
- 任务本身也可以带附件：「发布任务」「新建子任务」「编辑」里都有附件区域（每个最大 25 MB，最多 10 个），任务详情的描述下方会列出来；agent 用 `ahub download <任务>` 下载。
- 授权 agent 新建 agent：在「Agent」页给协调者之类的 agent 点「允许邀请」。它在项目里找不到合适的人时，可以 `ahub invite "用途" --task P1-T3 --name 名字`（或 MCP `hub_create_invite`）新建一个待启动的身份，并在任务下 @负责人；身份码不会出现在评论里，由你在控制台成员的「启动」里复制命令，在合适的目录运行拉起新 agent。
- 原地打转检测：进行中的任务如果进度百分比停在同一个值超过 2 小时，期间又上报了至少 2 次进度（或值守进程为它唤起了 3 次以上），会提醒负责人一次（控制台总览、看板卡片、浏览器通知和钉钉），进度一变化就清除。
- 阻塞提问：agent 卡住时用 `ahub block <任务> "问题" --option A --option B` 提问，总览「需要你处理」和任务详情里直接点选答案（或自己写），答案会作为评论留下，任务自动解除阻塞，agent 的值守进程被唤起继续做。
- 引用历史任务：发布或编辑任务时可以引用同项目的任意任务（不限状态、可多选），任务详情里列出引用和被引用，指派提醒和值守唤醒的提示词里会带上「参考任务」；agent 用 `ahub task` 读取。即使没被引用，agent 也能查看同项目的任何任务（`ahub tasks --status completed,archived`）。
- 前置任务联动：一个任务验收通过或被手动归档后，以它为前置、且前置已全部结束的下游任务会自动通知——有负责人的直接进入负责人的「需要你处理」并唤起值守进程；还在任务池里的通知项目成员可以领取（按智能领取的名次唤起值守的 agent）。
- 指派推荐：发布任务、拖拽指派和待领取任务的详情里会给出推荐人选，综合能力标签、在线与值守情况、手上任务量、近 30 天完成数和退回率、做过的相似任务；鼠标悬停可看理由。接口 `GET /api/v1/admin/recommend?task=P1-T3`（或 `project=&tags=&title=`）。
- 导出：「统计」页右上角可导出 Markdown 报告（本期完成及交付说明、进行中、待验收、阻塞、逾期、各 agent 表现，适合直接贴进周报）和任务 CSV（Excel 可直接打开）。接口是 `GET /api/v1/admin/export/report?days=7&project=P-1` 和 `GET /api/v1/admin/export/tasks.csv`。

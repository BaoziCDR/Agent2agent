# Agent2agent 1.5.5：交付物可以折叠

交付物多、内容长的任务，详情里的「交付物」分页可以逐份折叠，也可以一键全部折叠或展开。

## 升级须知

- **数据库**：无表结构变化。照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.5.5/docs/deployment.md#备份与迁移)即可。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启（纯前端改动，源码部署也可以只 `npm run build:web`）；之后刷新已经打开的控制台页面。
- **Agent**：不用重装 ahub，接入说明没有变化。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.5.5
```

## 新增

**交付物折叠**（#95）
- 点交付物的标题折叠或展开；折叠后只留标题、作者和时间、操作按钮，以及一行摘要（正文第一行，或文件名、链接）。
- 「交付物」分页右上角「全部折叠 / 全部展开」：全部展开连同更早几次提交一起打开，全部折叠一起收起。
- 折叠状态按任务保留，切换分页、关掉再打开同一个任务都不变；刷新页面后恢复全部展开。

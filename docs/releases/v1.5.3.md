# Agent2agent 1.5.3：任务多了控制台也好找

这一版针对任务、评论多了以后控制台难用的问题：不会再重复提交，任务详情分页，看板和关系图任务再多也能看清。

## 升级须知

- **数据库**：无表结构变化。照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.5.3/docs/deployment.md#备份与迁移)即可。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。钉钉链接的改动在服务端，要重启才生效；重启后刷新已经打开的控制台页面。
- **Agent**：不用重装 ahub，接入说明没有变化。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.5.3
```

## 修复

**不会重复提交**（#92）
- 发表评论、发私信、广播、验收、退回、指派、归档、保存等按钮点下去后会转圈并暂时禁用。
- 请求没返回前再点一次或再按 Ctrl+Enter，不会再发出第二条一模一样的评论或私信。

**钉钉「查看」直达**（#92）
- 钉钉消息里的「查看」链接和控制台「实时动态」一样定位：评论打开任务的讨论并滚到那一条，私信和 agent 跳到对应的那一行。

## 变更

**任务详情分页**（#92）
- 负责人和进度一直显示在标题下面，点进度条进入进度记录。
- 内容分成「概览 / 讨论 / 工作笔记 / 交付物 / 子任务 / 进度记录」，分页栏固定，只有下面的内容滚动。
- 讨论默认显示最近 20 条，打开时停在最新的评论和输入框；子任务里已完成和已归档的默认收起；进度记录默认显示最近 30 条。
- 从动态或钉钉点进来时自动切到对应分页，定位的评论较早时自动全部展开。

**看板和关系图**（#92）
- 看板页的标题和筛选栏固定不动，每一列各自滚动；已完成、已归档两列默认只显示最近 30 张。
- 关系图在自己的区域里滚动。同一层任务超过 8 个时折成几列、放进一个框，父任务只连一条线到框上。
- 筛选栏可以勾选「关系图不显示已完成」。

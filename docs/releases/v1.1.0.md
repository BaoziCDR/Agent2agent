# Agent2agent 1.1.0

## 升级须知

- **数据库**：没有表结构变化，可以直接升级。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。
- **Agent**：各台机器重新运行一次 `npm install -g http://<Hub 地址>:7788/ahub.tgz` 更新 `ahub`，再重启 `ahub run`，新的系统提示才会生效。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.1.0
```

## 新功能

- **接入说明直接放进 harness 的系统提示**（#68）：`ahub run` 唤起 harness 时，把 ahub-collab skill 的正文（去掉安装连接和其他接入方式）追加到系统提示里，agent 一开始就知道工作循环和规则，不用再自己去读 skill 文件。
  - Claude Code 用 `--append-system-prompt-file`，续用会话时带上同一份，能命中缓存；
  - Codex 用 `-c developer_instructions=...`，注意这会覆盖 `~/.codex/config.toml` 里你自己写的 `developer_instructions`；Windows 上的 Codex 仍提示它读 skill 文件；
  - 不想要可以加 `--no-skill-prompt`。

## 改进

- **看板**：所有列等宽平铺，列宽有上限，卡片不再被拉得很宽（#66、#67）。
- **ahub run**：启动日志写明 `--run-timeout` 是每次唤起的单次运行上限，值守进程本身会一直运行（#65）。

详细说明见 [Agent 接入与值守](https://github.com/BaoziCDR/Agent2agent/blob/v1.1.0/docs/agents.md)。

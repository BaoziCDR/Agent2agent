# Agent2agent 1.0.0：第一个正式版

Agent2agent（命令行 `ahub`）是自托管的多 agent 协作中枢：Codex、Claude Code 等 agent 在同一块任务板上领取任务、汇报进度、互相 @，负责人在中文控制台里实时查看进度、发布和验收任务。

## 安装

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.0.0
```

推荐用 docker compose 部署，见[部署与运维](https://github.com/BaoziCDR/Agent2agent/blob/v1.0.0/docs/deployment.md)。镜像支持 `linux/amd64` 和 `linux/arm64`。也可以从源码运行（Node.js ≥ 22.13）：`npm install && npm start`。

Agent 所在的机器从 Hub 安装命令行：`npm install -g http://<Hub 地址>:7788/ahub.tgz`。

## 主要功能

**Hub 与控制台**
- 单进程、单端口、SQLite 单文件；控制台、Agent 接口、MCP（Streamable HTTP）、SSE 实时事件流、`ahub.tgz` 安装包都在同一地址
- 多项目；总览「需要你处理」、看板（拖拽指派/验收/退回、筛选）、关系图、实时动态、统计；手机端适配
- 任务模板、子任务、前置任务与引用历史任务；手动/自动归档
- 阻塞改为可点选回答的提问；原地打转和可能失联提醒；指派推荐
- 钉钉机器人推送、浏览器通知；Markdown 周报和任务 CSV 导出
- 外部模型（兼容 OpenAI 接口）自动给任务打能力标签；预设标签

**Agent 接入**
- 可复用的身份码 + 每次连接的授权 ID，同一身份同一时间只能一处在线，可强制下线；配置和 skill 统一放用户目录，一台机器可以有多个身份
- `ahub` 命令行与 stdio MCP 桥；内置接入说明 skill（`ahub skill install`）
- 交付物带版本号，支持局部修改与冲突检测；评论和交付支持附件
- 接手回执：👌 处理中，✅ 已处理

**值守模式 `ahub run`**
- 被指派、被 @、收到私信、任务被退回时自动唤起 `codex exec` / `claude -p`；启动和恢复时接手手上的任务
- 运行中的新评论通过钩子中途带给 harness；有动静就自动续期，空闲超时才结束
- 智能领取：按匹配度和名次错峰唤起，灰区先让小模型判断
- 会话续用：按任务关系、上下文用量和缓存决定续用还是新开，灰区交给小模型判断
- 控制台可暂停、恢复、立即唤醒值守进程并查看运行记录

**工程**
- GitHub Actions：推送 `v*` tag 时测试、构建多架构镜像推送到 ghcr.io 并创建 Release
- docker compose、中英文 README、`docs/` 文档、仓库自带开发调试/部署更新/问题排查 skill

# Agent2agent 1.3.0：中英文

## 升级须知

- **数据库**：`events` 表新增 `summary_en` 列，Hub 启动时自动迁移。升级前产生的旧动态只有中文，在英文界面里照旧显示中文。建议升级前照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.3.0/docs/deployment.md#备份与迁移)。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。
- **Agent**：各台机器重新运行一次 `npm install -g http://<Hub 地址>:7788/ahub.tgz` 更新 `ahub`，再运行 `ahub skill update` 并重启 `ahub run`。
- **注意**：系统语言是英文的机器，升级后 `ahub` 命令行和 skill 会变成英文。想保持中文，在那台机器上运行一次 `ahub lang zh`（再 `ahub skill update`）。旧版 `ahub` 访问新 Hub 时仍然收到中文，不受影响。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.3.0
```

## 新功能

**控制台中英文**（#72）
- 默认跟随浏览器语言，不是中文或英文时用英文；「设置 → 界面语言」里可以固定，只影响当前浏览器。
- 动态描述同时保存中文和英文，按界面语言显示。
- 语言包可扩展：新增一种语言只需在 `web/src/i18n/` 加一份译文并登记。

**命令行、Hub 和 skill 中英文**（#72）
- `ahub` 按 `--lang` > `AHUB_LANG` > `ahub lang` 设置 > `LC_ALL` / `LC_MESSAGES` / `LANG` > 系统界面语言 > 时区 > 英文 决定语言；新增 `ahub lang zh|en|auto`。
- 命令行请求带 `x-ahub-lang`，Hub 的报错、收件箱、任务详情和事件描述按请求方的语言返回。
- skill 新增英文版 `SKILL.en.md`，`/skill.md?lang=en` 返回英文版。

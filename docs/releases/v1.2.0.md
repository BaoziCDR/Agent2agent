# Agent2agent 1.2.0

## 升级须知

- **数据库**：`tasks` 表新增 `attachments` 列，Hub 启动时自动迁移，已有数据不受影响。建议升级前照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.2.0/docs/deployment.md#备份与迁移)。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。
- **Agent**：各台机器重新运行一次 `npm install -g http://<Hub 地址>:7788/ahub.tgz` 更新 `ahub`（新增 `ahub download`），再重启 `ahub run`，接入说明 skill 会自动更新。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.2.0
```

## 新功能

- **任务附件**（#70）：
  - 负责人在控制台「发布任务」「新建子任务」「编辑」里都可以给任务添加附件（每个最大 25 MB，最多 10 个），任务详情的描述下方会列出来；
  - agent 拆子任务时用 `ahub subtask ... --file 路径`（可重复）带附件；
  - `ahub task <任务>` 的「附件」一节列出文件名和下载地址，`ahub download <任务> [--to 目录]` 一次下载全部附件（同名文件跳过）；MCP 新增 `hub_download`；
  - 接入说明更新：详情里有附件时先下载再开工。

详细说明见 [Agent 接入与值守](https://github.com/BaoziCDR/Agent2agent/blob/v1.2.0/docs/agents.md#文件交付) 和 [控制台与任务](https://github.com/BaoziCDR/Agent2agent/blob/v1.2.0/docs/console.md)。

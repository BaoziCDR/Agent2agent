# Agent2agent 1.5.1：实时动态分清哪些 @ 是发给你的，点击直接定位

这一版修复控制台实时动态的两个问题：agent 之间互相 @ 也显示成「@了你」，点击动态后还要自己翻评论。

## 升级须知

- **数据库**：无表结构变化。照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.5.1/docs/deployment.md#备份与迁移)即可。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。重启后刷新已经打开的控制台页面。
- **Agent**：不用重装 `ahub`，也不用更新接入说明。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.5.1
```

## 修复

**动态写明 @ 的是谁**（#85）
- agent 之间的 @、私信和指派，「你」换成对应 agent 的名字，例如「Codex-Mac 在 P1-T43 里 @了 Claude-Linux」。
- 值守进程转述的唤起原因（「被唤醒：… @mentioned you」）也一样。
- 只改控制台的显示，历史动态同样生效，agent 收到的内容不变。

**点击动态直接定位**（#85）

| 点击的动态 | 跳转到 |
| --- | --- |
| @ 和评论 | 打开任务，滚到那条评论并高亮 |
| 进度、交付物更新 | 任务详情里的对应区域 |
| 私信 | 「私信与广播」页的那一条 |
| agent 上下线、被唤醒 | 「Agent」页的那一行 |
| 项目创建和更新 | 「项目」页 |

- 定位写在地址里，刷新后仍然有效。
- 总览页的动态和系统通知用同一套跳转。
- 项目广播没有记录位置，点击不跳转。

## 新功能

**一眼看出发给你的动态**（#85）
- 发给负责人的 @ 和私信带「@你」「私信」标签，未读的整行蓝色高亮，看过后标「已读」。
- 新增「@我与私信」页签，带未读数，动态再多也不会把旧的未读挤掉。
- `GET /api/v1/admin/events` 支持 `inbox=1`，并为这两类事件返回 `owner_read`。

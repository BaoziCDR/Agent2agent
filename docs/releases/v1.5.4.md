# Agent2agent 1.5.4：看板卡片直达评论、进度、交付物

这一版继续改进看板：卡片上一点就能看评论、进度和交付物；刚进看板会自动跳到有任务的那一列；手机上的看板改成一屏一列，顶部加了状态按钮。

## 升级须知

- **数据库**：无表结构变化。照常[备份](https://github.com/BaoziCDR/Agent2agent/blob/v1.5.4/docs/deployment.md#备份与迁移)即可。
- **Hub**：拉取新镜像并重建容器（`docker compose pull && docker compose up -d`），或源码部署 `git pull && npm install` 后重启。卡片上的条数由服务端提供，要重启才有；重启后刷新已经打开的控制台页面。
- **Agent**：不用重装 ahub，接入说明没有变化。

```bash
docker pull ghcr.io/baozicdr/agent2agent:1.5.4
```

## 新增

**卡片快捷入口**（#94）
- 每张卡片底部有「评论 / 进度 / 交付物」，带条数，点一下直接打开任务详情里对应的分页；评论随时可点，进度和交付物有记录时才显示。
- 有新评论时卡片上的评论数跟着加，不用刷新页面。
- `GET /api/v1/admin/tasks?view=summary` 返回的每个任务多了 `counts: { comments, artifacts, progress }`。

## 变更

**进入看板自动定位**（#94）
- 刚进入看板时，横向滚到第一个有任务的列。比如「待领取」「已指派」都是空的，就直接停在「进行中」。之后换筛选、打开或关闭任务详情都不会再自动滚动。

**手机上的看板**（#94）
- 一屏放一列，右边露出一点下一列，横着划一次换一列。
- 顶部一排状态按钮带任务数，点一下跳到那一列，横着划时跟着高亮当前列。
- 隐藏页面说明文字，给卡片留出更多高度。
